# Спецификация: Telegram-агент анекдотов «Капибулка»

## Назначение и сценарий

Telegram-бот генерирует анекдоты на русском языке, принимает от пользователя оценку и комментарий, а затем учитывает обратную связь при подготовке следующих вариантов. Агент может присвоить анекдоту категорию юмора. Анекдоты, отзывы и категории сохраняются в PostgreSQL.

Основной сценарий MVP: пользователь запускает бота командой `/start` и отправляет тему обычным сообщением. Бот генерирует анекдот с категорией и кнопками оценки, сохраняет его в PostgreSQL. Следующее обычное сообщение считается комментарием к последнему анекдоту: бот сохраняет отзыв и создаёт улучшенный вариант в той же теме. Для совершенно новой темы пользователь отправляет `/new тема`; `/last` показывает последний сохранённый вариант. Также доступны `/joke`, `/rate` и `/feedback`.

## Компоненты и конфигурация

- Telegram Bot API — интерфейс пользователя. Локальный режим использует `getUpdates` через long polling; исходящий webhook должен быть отключён.
- Yandex AI Studio — генерация и улучшение текста с учётом доступной истории обратной связи.
- PostgreSQL — хранение анекдотов, категорий юмора и отзывов.
- Единые переменные конфигурации для локального запуска и Railway: `TELEGRAM_BOT_TOKEN`, `YANDEX_API_KEY`, `YANDEX_FOLDER_ID`, `YANDEX_MODEL_URI`, `YANDEX_BASE_URL`, `DATABASE_URL`.
- Секреты задаются через локальный `.env` или переменные окружения Railway и не попадают в Git.
- Railway запускает постоянный long-polling worker командой `python bot.py`, заданной в `railway.json`; публичный веб-сервер не нужен.

## Границы MVP

Включены генерация анекдотов, выдача через Telegram, приём оценки/комментария, сохранение данных и использование накопленных отзывов для последующих генераций. Категория юмора может быть задана или присвоена анекдоту.

Не входят веб-сайт или отдельная панель, платежи, пользовательские аккаунты вне Telegram, публикация в каналы, аналитические интерфейсы и сложная система модерации. Реальные секреты и пользовательские данные не хранятся в репозитории.

## Наблюдаемые критерии готовности

- Локальный запуск подключается к Telegram через long polling, когда webhook отключён.
- Команда или понятное действие пользователя возвращает новый русскоязычный анекдот, сгенерированный Yandex AI Studio.
- Пользователь может оставить оценку и комментарий к полученному анекдоту.
- Анекдот, категория и обратная связь сохраняются в PostgreSQL и связаны между собой.
- При последующем запросе генерация учитывает сохранённую обратную связь.
- Все шесть переменных из README используются единообразно в локальном и Railway окружениях; секреты не отслеживаются Git.
- В Railway подключён PostgreSQL; `DATABASE_URL` сервиса бота ссылается на URL базы, бот запускается одной репликой и остаётся активным.
